#Use this code as a reference.
First run 'pip install -r requirements.txt' in the terminal, to download the needed repertoires.
Then run 'indexer.py' to create your own 'indexdir' folder.
after that run 'python app.py' to run the main file.
finally either type http://127.0.0.1:5000 in your browser or (click + ctrl ) on it from the terminal.
